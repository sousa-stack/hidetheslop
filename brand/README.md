# Brand

Kevin Sousa made the Hide the Slop logo by combining two icons from [SVG Repo](https://www.svgrepo.com/): a robot and a red "no" sign. `logo-1024.png` is the finished picture, and `logo.vectorcraft` is its editable source.

## Where the icons came from

| Part | Icon page | Creator | License |
|---|---|---|---|
| Robot | [SVG Repo](https://www.svgrepo.com/svg/398223/robot) | [Noto Emoji](https://github.com/googlefonts/noto-emoji), Copyright 2013 Google LLC | Apache 2.0 on SVG Repo; see below |
| Red "no" sign | [SVG Repo](https://www.svgrepo.com/svg/474763/cancel) | Flat Colored Interface Icons, uploaded by SVG Repo | CC0 |

Noto Emoji's README says its image resources are under Apache 2.0, but its `LICENSE` file changed to the SIL Open Font License in July 2024. Both allow this use, so [`extension/src/icons/NOTICE.txt`](../extension/src/icons/NOTICE.txt) includes both texts, and it ships inside the extension next to the icons. Keep it there.

Vectors and icons by [SVG Repo](https://www.svgrepo.com).

## Using the logo

The MIT license for the rest of this repo doesn't cover the files in this folder, or the icons made from them in `extension/src/icons/`. The two original icons stay under their own licenses, and nothing here claims ownership of them. If you publish a fork, use your own name and icons.
